# BODY QUEST

iPhone向けの食事・体重・運動トラッカー。PWAとしてホーム画面に追加でき、記録は端末内のIndexedDBに保存します。Geminiは任意の明示操作で利用します。

## ローカル起動

Node.js 24以上。`npm ci` → `npm run dev`。`npm test`で栄養計算とAPIの検証、`npm run build`で型検査とPWAビルド。

AIを使う場合だけ `.env.example` を `.env.local` にコピーして設定します。APIキーをGitHubへ保存したり、`VITE_`から始まる変数に入れないでください。

## Vercelへの公開

1. Vercelの **Add New → Project** からこのGitHubリポジトリをImport。
2. Frameworkは **Vite**、Buildは `npm run build`、Outputは `dist`。Node.js 24。
3. 以下の環境変数をProductionと必要なPreview環境に設定してDeploy。

| 変数 | 内容 |
|---|---|
| `GEMINI_API_KEY` | Google AI Studioで取得済みのキー |
| `GEMINI_MODEL` | 自分のプロジェクトで利用できる無料枠のモデル名。例 `gemini-3.5-flash-lite`。Googleの最新の提供状況・料金を確認 |

公開後は食事の読み取り・コーチのボタンから直接AIを利用できます。パスワード入力はありません。Geminiキーはサーバーで管理します。環境変数の変更後は再Deployが必要です。サーバー設定がなくても基本の記録は使えます。

無料枠はGoogleとVercelの条件に依存します。有料APIに自動で切り替えません。自動AI呼び出しなし。AI APIは同じサイトからのJSONリクエストを受け付けます。パスワードによる利用者認証はなく、公開アプリを開いた人もAIボタンを使えます。Geminiプロジェクトが既に課金対象なら無料であることは保証できないため、Google側の設定を確認してください。インスタンス内の30回/時制限は補助であり、分散したデプロイ全体の厳密な上限ではありません。

## iPhoneでの利用

SafariでProduction URLを開き、共有 → ホーム画面に追加。追加したアイコンから使い始めてください。SafariとPWAで記録が共有されない場合は、バックアップを書き出して復元します。

最初に「目標を設定する」から身長・年齢・開始体重・目標体重・活動量を入力。イベント名と目標日、または3か月・6か月・1年後の長期目標を選べます。自動モードではカロリー・PFCが同時に設定され、朝の体重記録で更新。食事配分・週間予算も連動します。手動モードでは入力値を維持。古いバックアップの栄養目標は自動で上書きしません。

「計画」では、現在の設定での期限時の体重、選択モードの制限内で減量を最大化した体重、目標までの期間・候補日を比較できます。候補日に延長する、期限に合う目標体重へ変更する操作も用意しています。通常モードは推定基礎代謝以上。「基礎代謝未満も含む詳細調整」は説明を確認してチェックすると有効になります。どちらも1,600kcalの下限、推定消費20%・体重0.75%/週の赤字上限を残します。新しい手動目標にも適用し、既存の手動目標を読み込み時に変更しません。基礎代謝との大小だけでは安全性を判断できず、体重・期間はモデル試算で、安全性や実際の達成を保証しません。

「今日」画面は朝の体重入力、今日の残り、各タブへのボタンだけです。体重は前回値が入った状態から±0.1kgで調整して保存し、保存後は1行の表示になります。目標未設定の間は残りではなく記録した量を表示します。食事タブは上から「朝昼夕・間食」→「履歴から／文章・写真／食品リスト」を選んで入力し、ワンタップ追加は通知から取り消せます。食事は記録した内容が量・栄養値ごと履歴に残り、「よく食べる」「最近」「セット（いつもの組み合わせ）」「前日の同じ食事」からワンタップで追加できます。時間帯に合わせて朝食・昼食・夕食・間食が自動で選ばれます。

たんぱく質カードでは残りのg数、1食あたりの目安、カロリーの残りに合う高たんぱく食品（プロテイン・サラダチキン・ギリシャヨーグルト・卵・納豆・豆腐・ツナ）をワンタップで追加できます。運動画面では家・ジム・外・回復のメニューから、曜日の状況・前回の筋トレ・今週の回数（週2〜3回）に合わせた「今日のおすすめ」を表示し、前回の記録をもとに回数・重さの伸ばし方を案内します。

AIの食事読み取りは登録食品・よく食べる食事の値を優先し、複数の料理をまとめて記録、量の倍率調整、マイ食品への保存ができます。コーチは今日の残りカロリー・たんぱく質・おすすめ運動を踏まえて答え、続けて質問できます（直近4往復を送信）。

アドバイスはやさしめ・バランス・厳しめを切替可能。食品のお気に入り、週間振り返り、CSV出力を無料で使えます。

## データとプライバシー

- クラウド同期なし。公開リポジトリに個人の記録やキーを保存しません。
- 端末の保存容量不足はエラーを表示します。ブラウザデータ削除・機種変更に備え、週1回のJSONバックアップを推奨。
- バックアップには食事・体重・運動・体の写真が含まれます。安全な保存場所に保管してください。復元は検証後に全記録を置き換えます。
- Geminiに送る内容は画面に表示。AI送信時に最近の健康記録もGoogleへ送られます。無料枠のデータ取扱いは [Geminiの利用規約](https://ai.google.dev/gemini-api/terms) を確認してください。
- 食事写真は読み取りのためGoogleへ送る場合があります。体の経過写真は端末内に保存し、AIには送信しません。

## 栄養と運動の扱い

一般的な食品・レシピの値は目安。商品の栄養表示・チェーン公式値を優先して修正できます。食品のPFC換算はラベルのカロリーと必ず一致するわけではありません。ハイボールのアルコール由来の熱量はPFCと別に含まれます。

作り置きでは「100gあたり」の材料データを使用し、完成後の重量で分けます。米は炊飯後、鶏肉は生の重量で記録。鶏肉は中心75℃で1分以上の加熱を確認してください。

朝の平均は記録のある日だけで計算し、朝夜を混ぜません。前週比較には各週4日以上が必要です。消費カロリーを食事目標へ自動加算しません。医療上の診断・服薬変更・体脂肪率の写真推定は行いません。
