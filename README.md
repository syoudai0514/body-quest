# BODY QUEST

iPhone向けの食事・体重・運動トラッカー。PWAとしてホーム画面に追加でき、記録は端末内のIndexedDBに保存します。Geminiは任意の明示操作で利用します。

## ローカル起動

Node.js 24以上。`npm ci` → `npm run dev`。`npm test`で栄養計算とAPIの検証、`npm run build`で型検査とPWAビルド。

AIを使う場合だけ `.env.example` を `.env.local` にコピーして設定します。APIキーをGitHubへ保存したり、`VITE_`から始まる変数に入れないでください。

## Vercelへの公開

1. Vercelの **Add New → Project** からこのGitHubリポジトリをImport。
2. Frameworkは **Vite**、Buildは `npm run build`、Outputは `dist`。Node.js 24。
3. 以下の環境変数をProductionと必要なPreview環境に設定してDeploy。

| 変数 | 内容 |
|---|---|
| `GEMINI_API_KEY` | Google AI Studioで取得済みのキー |
| `GEMINI_MODEL` | 自分のプロジェクトで利用できる無料枠のモデル名。例 `gemini-3.5-flash-lite`。Googleの最新の提供状況・料金を確認 |

公開後は食事の読み取り・コーチのボタンから直接AIを利用できます。パスワード入力はありません。Geminiキーはサーバーで管理します。環境変数の変更後は再Deployが必要です。サーバー設定がなくても基本の記録は使えます。

無料枠はGoogleとVercelの条件に依存します。有料APIに自動で切り替えません。AIの自動更新は初期状態では無効で、トップの「朝昼晩に自動更新」を有効にすると1日3つの時間帯ごとに最大1回、開いているアプリから呼び出します（手動更新・相談は別）。AI APIは同じサイトからのJSONリクエストを受け付けます。パスワードによる利用者認証はなく、公開アプリを開いた人もAIボタンを使えます。Geminiプロジェクトが既に課金対象なら無料であることは保証できないため、Google側の設定を確認してください。インスタンス内の30回/時制限は補助であり、分散したデプロイ全体の厳密な上限ではありません。

## iPhoneでの利用

SafariでProduction URLを開き、共有 → ホーム画面に追加。追加したアイコンから使い始めてください。SafariとPWAで記録が共有されない場合は、バックアップを書き出して復元します。

最初に「目標を設定する」から身長・年齢・開始体重・目標体重・活動量を入力。イベント名と目標日、または3か月・6か月・1年後の長期目標を選べます。自動モードではカロリー・PFCが同時に設定され、朝の体重記録で更新。食事配分・週間予算も連動します。手動モードでは入力値を維持。古いバックアップの栄養目標は自動で上書きしません。

「計画」では、現在の設定での期限時の体重、選択モードの制限内で減量を最大化した体重、目標までの期間・候補日を比較できます。候補日に延長する、期限に合う目標体重へ変更する操作も用意しています。通常モードは推定基礎代謝以上。「基礎代謝未満も含む詳細調整」は説明を確認してチェックすると有効になります。どちらも1,600kcalの下限、推定消費20%・体重0.75%/週の赤字上限を残します。新しい手動目標にも適用し、既存の手動目標を読み込み時に変更しません。基礎代謝との大小だけでは安全性を判断できず、体重・期間はモデル試算で、安全性や実際の達成を保証しません。

「今日」画面は「今日の作戦」、朝・夜の体重、今日の残り、なんでも相談、各タブへのボタンです。作戦は記録からすぐ表示でき、Geminiで短いアドバイスを作成・再判定できます。朝の7日平均、2週間各4日以上の朝の記録がある場合の1週間後の平均目安、週の予算、未記録の朝・夜の体重、実際の履歴にある食事の確認などを案内します。速すぎる減量や記録不足では予測を控え、食べ過ぎは確定した日だけを判定。体重は朝／夜を選び、同じ時間の前回値から±0.1kgで調整して保存し、保存後は短く表示します。夜の記録は朝の平均には混ぜません。目標未設定の間は残りではなく記録した量を表示します。食事タブは上から「朝昼夕・間食」→「履歴から／文章・写真／食品リスト」を選んで入力し、ワンタップ追加は通知から取り消せます。食事は記録した内容が量・栄養値ごと履歴に残り、「よく食べる」「最近」「セット（いつもの組み合わせ）」「前日の同じ食事」からワンタップで追加できます。時間帯に合わせて朝食・昼食・夕食・間食が自動で選ばれます。

たんぱく質カードでは残りのg数、1食あたりの目安、カロリーの残りに合う高たんぱく食品（プロテイン・サラダチキン・ギリシャヨーグルト・卵・納豆・豆腐・ツナ）をワンタップで追加できます。運動画面では「歩く・消費」「自宅トレ」「ジム・基本」「ジム・本格」を選びます。1駅分歩く・ゆるウォーキング・早歩き・バイクは実際の時間に直して記録でき、安静時との差分の消費を推定します。本格ジムは目的（筋肥大／筋力／体力）、週2〜6回、1回の時間を設定でき、上半身／下半身の分割例と回復を踏まえたおすすめを表示。自分の種目も重量・回数・セット・RIR（あと何回できたか）・ウォームアップ付きで保存・修正できます。同じ種目の前回の実績と比較し、ウォームアップを除いたセット数・最大記録重量・総負荷（kg×回）を表示します。総負荷の増加をそのまま筋力の伸びと判定しません。AI運動入力は実施した内容を種目ごとの短い一覧（例：40kg × 10回 × 3セット）に整理し、正しければそのまま保存、修正時はその種目だけを開いて短い表で編集できます。余力・準備セットは必要なときだけ編集を表示します。相談には方針と最近の実績を渡します。未記載の重量・回数・RIRを実績として埋めません。

AIの食事読み取りは今回の栄養表示写真を最優先にし、表示がない場合は商品・調理状態・分量の合う登録食品と履歴を使い、複数の料理をまとめて記録、量の倍率調整、マイ食品への保存ができます。コーチは今日の残りカロリー・たんぱく質・おすすめ運動を踏まえて答え、睡眠・習慣・一般的な悩みも相談できます。トップとコーチタブは同じ日付の会話を共有し、続けて質問できます（直近4往復を送信）。会話は起動中に保持。作戦アドバイスは最大90件を端末・バックアップへ保存し、記録変更で古くなったものは再判定を案内します。

「計画」タブの最初には「道のり」カードがあり、開始からの減量・達成率・実測ペースと必要ペースの比較（順調／速い／ゆっくり／速すぎ）・連続記録・累計の赤字・自己ベスト・1kgごとのマイルストーンを表示します。実測ペースに応じて、目標日を延ばす・目標を上げる/調整するを確認つきのワンタップで提案します。体重グラフには目標までの計画線、週の振り返りには前週比と「今週よかったこと」が出ます。計算の詳細や記録一覧は折りたたみです。今日の画面で収支を確定でき、自己ベストやマイルストーンは保存時にお祝いします。

遊び要素（設定でオフ可）：記録・食事・たんぱく質・運動・収支の確定でXPがたまり、レベルと称号が上がります。今日の画面は「デイリークエスト」、計画タブには目標を「魔王」に見立てたHPバーと称号コレクション。食事を抜いたり減らしたりしてもXPは増えません。

アドバイスはやさしめ・バランス・厳しめを切替可能。食品のお気に入り、週間振り返り、CSV出力を無料で使えます。

自動更新はトップの「ヒントとAIの更新設定」から有効にします。朝0〜10時・昼11〜16時・夜17〜23時に、トップを開いている／戻ったときに各1回生成し、タブ切替や再読み込みで重複しません。失敗時は自動再試行せず、手動で再判定できます。閉じたアプリの裏で動く処理やプッシュ通知はありません。

## 食品の検索・計算・管理

「食事」→「食品・メーカーを探す」で、登録食品と文科省の標準食品2,537件を検索できます。市販品は「メーカー表示を検索」で公式の商品ページを探し、実際の栄養表の値を取得。検索語だけをGoogleへ送り、健康記録は送りません。味・容量・基準量を確認し、食べたg/mlまたは倍率を入力します。計算の根拠は折りたたみから確認できます。メーカーの表が確認できない場合は栄養表示写真・手入力へ案内し、推測を公式値として扱いません。

「食品を管理」では要確認の食品、表示値の修正、最大10件の修正履歴からの復元、非表示と再表示を操作できます。修正は次回の入力から適用し、過去の食事には当時の値と出典を保持。作り置きは材料の成分値・使用量・出典・完成重量を保存します。計算では途中の丸めを行わず、gとmlや生と調理後を混同しません。[データソースと計算・保存の詳細](docs/nutrition-data.md)を参照してください。

## データとプライバシー

- クラウド同期なし。公開リポジトリに個人の記録やキーを保存しません。
- 端末の保存容量不足はエラーを表示します。ブラウザデータ削除・機種変更に備え、週1回のJSONバックアップを推奨。
- バックアップには食事・体重・運動・体の写真・保存したAI作戦が含まれます。安全な保存場所に保管してください。復元は検証後に全記録を置き換えます。
- Geminiに送る内容は画面に表示。AI送信時に最近の健康記録もGoogleへ送られます。無料枠のデータ取扱いは [Geminiの利用規約](https://ai.google.dev/gemini-api/terms) を確認してください。
- 食事写真は読み取りのためGoogleへ送る場合があります。体の経過写真は端末内に保存し、AIには送信しません。

## 栄養と運動の扱い

一般的な食品・レシピの値は目安。商品の栄養表示・チェーン公式値を優先して修正できます。食品のPFC換算はラベルのカロリーと必ず一致するわけではありません。ハイボールのアルコール由来の熱量はPFCと別に含まれます。

作り置きでは「100gあたり」の材料データを使用し、完成後の重量で分けます。米は炊飯後、鶏肉は生の重量で記録。鶏肉は中心75℃で1分以上の加熱を確認してください。

朝の平均は記録のある日だけで計算し、朝夜を混ぜません。前週比較には各週4日以上が必要です。消費カロリーを食事目標へ自動加算しません。医療上の診断・服薬変更・体脂肪率の写真推定は行いません。
